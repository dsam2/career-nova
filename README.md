# CareerNova Education Services

CareerNova is a modern education and admissions consultancy platform tailored specifically for Indian higher education, university selection, CAP rounds, and professional career profiling.

## Overview
- **Admissions Counselling Support**: One-on-one personalized mentorship across central, state, and private universities in India.
- **Career Assessment & Profiling**: Psychometric evaluations and aptitude mapping for stream and degree selection.
- **College & Course Selection**: Data-backed institutional shortlisting (NIRF, NAAC, audited placement reports).
- **Entrance Exam Guidance**: Strategic roadmaps and cutoffs analysis for JEE, NEET, CUET, CAT, and State CETs.
- **Application & Documentation**: Error-free centralized portal submissions and quota certification audits.
- **Scholarships & Financial Aid**: National Scholarship Portal (NSP), TFWS concessions, and low-interest loan advisory.
- **Direct & Institutional Guidance**: Transparent, regulatory-compliant counsel for institutional quotas and spot rounds.

## Quickstart

### Prerequisites
- Node.js (v18+)

### Run Locally
```bash
# Clone the repository
git clone https://github.com/dsam2/career-nova.git
cd career-nova

# Start the preview server
npm start
```
The application will be served locally at `http://127.0.0.1:8080/`.
