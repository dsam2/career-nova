## Project Tech Stack Summary

* **Framework**: Next.js 14+ (App Router, SSG static pre-rendering)
* **Styling**: Tailwind CSS (with custom Career Nova color and animation extensions)
* **Animations**: Framer Motion (identical spring physics to Framer engine)
* **Icons**: Lucide React
* **Hosting**: Vercel Edge Network
